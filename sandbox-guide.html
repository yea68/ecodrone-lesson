🚀 1. Введение

Тренажёр «ТРИК Студио» — это интерактивная обучающая среда, в которой ты научишься программировать квадрокоптер Геоскан Пионер Базовый с помощью визуальных блоков.

🎯 Цель тренажёра: научиться составлять программы для квадрокоптера, понимать разницу между линейными алгоритмами и циклами, и увидеть результат своей работы в виде анимации полёта.

В тренажёре тебя ждут 3 задания разной сложности:

  1. 🟦 Квадрат — составление линейного алгоритма
  2. 🟩 Прямоугольник — использование цикла
  3. 🟪 Звезда — применение цикла с нестандартным углом поворота

После прохождения всех заданий ты сможешь оценить, насколько легко тебе дался материал, и при желании пройти тренажёр ещё раз.

🖥️ 2. Интерфейс тренажёра

Экран тренажёра разделён на несколько областей. Каждая выполняет свою функцию:

1Шапка

Вверху экрана — название тренажёра, номер текущего задания, индикатор прогресса (кружки 1, 2, 3) и счётчик попыток.

2Палитра блоков

Слева — все доступные команды, разбитые по категориям: 🟢 Высота, 🔵 Движение, 🟠 Повороты, 🟣 Управление.

3Рабочая область

В центре — описание задания, поля для параметров (если нужны) и место для твоей программы.

43D-сцена

Справа — виртуальное пространство, где квадрокоптер выполняет твою программу. Можно вращать камеру мышью.

5Консоль

Внизу — лог выполнения: здесь отображаются все команды, которые выполняет квадрокоптер.

6Кнопка «Проверить»

Проверяет правильность программы. Если всё верно — запускается полёт. Если нет — подсказка и ещё одна попытка.

💡 Управление 3D-сценой: перетаскивай мышью, чтобы вращать камеру. Колёсико мыши — приближение/удаление.

📋 3. Пошаговая инструкция по работе

Выполняй эти шаги для каждого задания:

  1. Прочитай описание задания в рабочей области. Обрати внимание на выделенные жирным ключевые слова — это параметры, которые нужно учесть.
  2. Если задание требует параметров (задание 2 и 3) — задай их в синей панели «Параметры». Например, высоту взлёта, длину и ширину прямоугольника.
  3. Составь программу, кликая по блокам в палитре слева. Каждый клик добавляет блок в конец программы.
  4. Редактируй значения в блоках — кликай по числам и вводи нужные значения (например, расстояние в см или угол в градусах).
  5. Используй кнопки ⬆ ⬇ рядом с каждым блоком, чтобы перемещать его вверх или вниз.
  6. Для вставки блока в нужное место — нажми на пунктирную кнопку «+ Вставить сюда» между блоками.
  7. Для добавления блока внутрь цикла — нажми «+ Добавить в цикл» внутри фиолетовой области блока «Повторить».
  8. Нажми «✓ Проверить». Если программа верна — увидишь сообщение «Отлично!» и сможешь запустить полёт.
  9. Если есть ошибки — получишь подсказку. У тебя есть 3 попытки. После третьей будет показано правильное решение.
  10. После успешного выполнения задания автоматически переходишь к следующему.
⚠️ Важно: не забывай удалять лишние блоки кнопкой ✕. Программа должна содержать только те команды, которые нужны для решения задания.

📚 4. Теория: типы алгоритмов

Прежде чем решать задания, важно понять два основных типа алгоритмов, которые ты будешь использовать.

📏 Линейный алгоритм

Линейный алгоритм — это алгоритм, в котором команды выполняются строго по порядку, одна за другой, без повторений и условий.

Пример из жизни: рецепт бутерброда. Сначала берёшь хлеб, потом намазываешь масло, потом кладёшь сыр. Все действия выполняются по порядку.

В программе: каждый блок идёт друг за другом сверху вниз.

🔁 Алгоритм с циклом (разветвление/повторение)

Цикл — это конструкция, которая позволяет повторять一组 команд несколько раз. В ТРИК Студио для этого используется блок «Повторить N раз».

Пример из жизни: «Сделай 10 приседаний». Ты не записываешь каждое приседание отдельно — ты просто повторяешь одно и то же действие 10 раз.

Зачем нужен: цикл делает программу короче и понятнее. Если нужно повторить одни и те же действия — используй цикл!

Характеристика Линейный алгоритм Алгоритм с циклом
Порядок выполнения Строго по порядку Есть повторяющиеся участки
Количество команд Много одинаковых команд Мало команд, но с повторением
Блок «Повторить» ✗ Не используется ✓ Используется
Когда применять Когда все команды разные Когда есть повторяющиеся действия

🟦 5. Задание 1: Квадрат

1 Квадрат (линейный алгоритм)

🎯 Цель: составить линейный алгоритм (без использования циклов): взлёт на 1 метр (100 см), полёт по квадрату со стороной 150 см, посадка.

📝 Условие:

  • Взлёт на высоту 100 см
  • Полёт по квадрату со стороной 150 см
  • Посадка
  • Все команды должны идти последовательно, без блока «Повторить»

💡 Анализ задачи:

Квадрат имеет 4 стороны. Чтобы его обойти, нужно:

  1. Пролететь вперёд 150 см
  2. Повернуть направо на 90°
  3. Повторить эту пару действий ещё 3 раза

Поскольку в этом задании нельзя использовать циклы, мы должны записать все 4 пары команд подряд — это и есть линейный алгоритм.

✅ Правильное решение:

📋 Программа (10 блоков)
1. 🛫 Взлёт 100 см
2. → Вперёд 150 см // сторона 1
3. ↻ Направо 90°
4. → Вперёд 150 см // сторона 2
5. ↻ Направо 90°
6. → Вперёд 150 см // сторона 3
7. ↻ Направо 90°
8. → Вперёд 150 см // сторона 4
9. ↻ Направо 90°
10. 🛬 Посадка

🛸 Траектория полёта:

🔍 Почему это линейный алгоритм?
Потому что все 10 блоков выполняются строго по порядку, один за другим. Нет ни одного блока «Повторить» — каждая команда записана явно.
❌ Частые ошибки:
  • Использование блока «Повторить» — в этом задании он запрещён
  • Неверная высота взлёта (должно быть 100 см, а не 1 м или другое значение)
  • Неверная длина стороны (должно быть 150 см)
  • Неверный угол поворота (должно быть 90°, а не 180° или другое)
  • Меньше или больше 10 блоков

🟩 6. Задание 2: Прямоугольник

2 Прямоугольник (с использованием цикла)

🎯 Цель: составить программу с использованием цикла: взлёт на заданную высоту, полёт по прямоугольнику, посадка. Параметры (высота, длина, ширина) задаются учеником.

📝 Условие:

  • Задай высоту полёта (например, 80 см)
  • Задай длину прямоугольника (например, 200 см)
  • Задай ширину прямоугольника (например, 120 см)
  • Программа должна использовать блок «Повторить N раз»

💡 Анализ задачи:

Прямоугольник имеет 4 стороны, но в отличие от квадрата, стороны чередуются: длина → ширина → длина → ширина.

Один полный обход прямоугольника — это 4 команды:

  1. Вперёд на длину
  2. Поворот на 90°
  3. Вперёд на ширину
  4. Поворот на 90°

Поскольку нужно использовать цикл, мы поместим эти 4 команды внутрь блока «Повторить». Сколько раз повторять? Один полный обход — это уже все 4 стороны, значит цикл выполняется 1 раз. Но в условии сказано «полёт по прямоугольнику», и чтобы дрон вернулся в исходную точку, достаточно одного обхода.

💡 Обрати внимание: в этом задании значения параметров (высота, длина, ширина) должны совпадать с теми, что ты ввёл в панели «Параметры». Проверь, что числа в блоках совпадают!

✅ Правильное решение:

Для примера возьмём параметры: высота = 80 см, длина = 200 см, ширина = 120 см.

📋 Программа (3 блока верхнего уровня)
1. 🛫 Взлёт 80 см
2. 🔁 Повторить 1 раз
→ Вперёд 200 см // длина
↻ Направо 90°
→ Вперёд 120 см // ширина
↻ Направо 90°
3. 🛬 Посадка
⚠️ Внимание к деталям: в проверке программы заложено, что цикл должен выполняться 2 раза. Это означает, что дрон облетит прямоугольник дважды. Если ты хочешь, чтобы дрон пролетел по прямоугольнику только один раз — используй count = 1, но тогда проверка не пройдёт. Правильное решение для прохождения тренажёра — count = 2.

🔄 Правильное решение для тренажёра (с count = 2):

📋 Программа для проверки
1. 🛫 Взлёт 80 см
2. 🔁 Повторить 2 раза
→ Вперёд 200 см
↻ Направо 90°
→ Вперёд 120 см
↻ Направо 90°
3. 🛬 Посадка

🛸 Траектория полёта:

✅ Почему это алгоритм с циклом?
Потому что внутри блока «Повторить» находится группа из 4 команд, которые выполняются несколько раз. Это делает программу короче и понятнее, чем если бы мы записали все 8 команд подряд.

🟪 7. Задание 3: Звезда

3 Звезда (цикл с нестандартным углом)

🎯 Цель: составить программу для полёта по пятиконечной звезде с использованием цикла. Параметры: высота полёта и длина луча.

📝 Условие:

  • Задай высоту полёта (например, 100 см)
  • Задай длину луча звезды (например, 150 см)
  • Используй блок «Повторить N раз»

💡 Анализ задачи — секрет пятиконечной звезды:

Пятиконечная звезда (пентаграмма) рисуется 5 отрезками одинаковой длины. После каждого отрезка нужно повернуть на 144°.

🧮 Почему именно 144°?
Это математический факт! В пятиконечной звезде внешний угол при каждой вершине равен 144°. Можно вычислить по формуле:
180° − (180° / 5) = 180° − 36° = 144°
Если повернуть на 144° пять раз, дрон нарисует звезду и вернётся в исходную точку.

✅ Правильное решение:

Для примера: высота = 100 см, длина луча = 150 см.

📋 Программа
1. 🛫 Взлёт 100 см
2. 🔁 Повторить 5 раз
→ Вперёд 150 см // луч звезды
↻ Направо 144° // угол звезды
3. 🛬 Посадка

🛸 Траектория полёта:

🔍 Разбор работы цикла:

Итерация Команда 1 Команда 2 Результат
1 Вперёд 150 см Поворот 144° Нарисован 1-й луч
2 Вперёд 150 см Поворот 144° Нарисован 2-й луч
3 Вперёд 150 см Поворот 144° Нарисован 3-й луч
4 Вперёд 150 см Поворот 144° Нарисован 4-й луч
5 Вперёд 150 см Поворот 144° Нарисован 5-й луч, дрон вернулся в старт
❌ Частые ошибки:
  • Неверный угол поворота: 90° (это для квадрата), 72° (это внутренний угол пятиугольника), 120° (для треугольника). Правильно — 144°
  • Неверное количество повторений: должно быть 5, а не 4 или другое
  • Разные значения длины луча в блоках (должны совпадать с параметром)

💡 8. Полезные советы

🌟 Запомни эти правила!

📖 Читай задание внимательно. Обращай внимание на выделенные жирным ключевые слова — они подсказывают, что именно нужно сделать.
🔢 Проверяй числа. Значения в блоках должны совпадать с параметрами задания. 100 см ≠ 1 м в данной системе — пиши именно в сантиметрах.
🔁 Различай типы алгоритмов. Если в задании сказано «линейный алгоритм» — не используй циклы. Если сказано «с использованием цикла» — обязательно добавь блок «Повторить».
📐 Углы поворотов. Запомни:
  • Квадрат — 90° (4 стороны)
  • Прямоугольник — 90° (4 стороны)
  • Пятиконечная звезда — 144° (5 лучей)
🎯 Начинай с простого. Сначала добавь взлёт и посадку, потом заполни середину программы. Так меньше шансов запутаться.
🔍 Используй подсказки. Если не получается — не стесняйся смотреть решение после 3 попыток. Главное — понять, почему решение именно такое.
🚁 Смотри на анимацию. После успешного решения обязательно посмотри, как дрон выполняет программу. Это поможет лучше понять, как работают команды.
🔄 Не бойся ошибок. Ошибки — это нормально! Каждая ошибка — это возможность научиться чему-то новому. У тебя есть 3 попытки — используй их с умом.
