Тема: Знакомство со средой программирования ТРИК Студио

⚠️ Важное уточнение по языкам программирования:

В ТРИК Студио поддерживаются разные языки программирования в зависимости от платформы:

  • Python — для программирования роботов на платформе ТРИК
  • Lua — для программирования квадрокоптера «Геоскан Пионер»
  • JavaScript — также доступен для некоторых платформ

При проверке заданий 4 учитывать эту особенность.

📋 Задание 1: Интерфейс программы
1 Правильные ответы для таблицы:
Элемент интерфейса Назначение
Палитра блоков Содержит все доступные блоки для программирования (движение, датчики, циклы и т.д.)
Рабочее поле Основная область для создания программы путем соединения блоков
Панель инструментов Содержит кнопки для управления программой (запуск, остановка, сохранение, выбор языка программирования)
Окно симуляции Показывает виртуального робота и трассу для тестирования программы
Консоль Отображает сообщения об ошибках, отладочную информацию и результаты выполнения
Примечание: Принимаются любые ответы, передающие суть назначения элементов. Ключевые слова: палитра - блоки/команды, рабочее поле - создание программы, панель - управление, симуляция - тестирование, консоль - ошибки/сообщения.
📋 Задание 2: Основные блоки
2 Правильный ответ:

Все блоки должны быть отмечены ✓

  • Блок "Двигаться вперед"
  • Блок "Повернуть"
  • Блок "Ожидание"
  • Блок "Цикл"
  • Блок "Условие"
  • Блок "Датчик"
  • Блок "Звук"
  • Блок "Переменная"
Примечание: Это ознакомительное задание. Ученик должен найти все перечисленные блоки в палитре программы.
📋 Задание 3: Практическая работа
3 Правильная последовательность блоков:
1 Блок "Двигаться вперед" - установить время или расстояние движения
2 Блок "Повернуть направо" - установить угол поворота (90°)
3 Блок "Остановиться" или завершение программы

Альтернативные варианты:

  • Двигаться вперед → Повернуть (направо) → Двигаться вперед (короткое расстояние) → Стоп
  • Использовать блок "Ожидание" между командами
Примечание: Принимаются любые логичные последовательности, выполняющие задачу. Важно: движение вперед, поворот направо, остановка.
📋 Задание 4: Режимы программирования
4 Правильные ответы:

1. Какие режимы программирования поддерживает ТРИК Студио?

Визуальное (блочное) программирование и текстовое программирование. Поддерживаются разные языки в зависимости от платформы.

2. В чем разница между визуальным и текстовым программированием?

Визуальное: программа составляется из графических блоков (картинок), которые соединяются между собой. Не требует знания синтаксиса языка программирования.

Текстовое: программа пишется кодом на языке программирования. Требует знания синтаксиса и команд языка.

3. Какой язык программирования используется в текстовом режиме?

В ТРИК Студио поддерживаются разные языки в зависимости от платформы:

Платформа ТРИК Python и JavaScript
Квадрокоптер «Геоскан Пионер» Lua
LEGO Mindstorms EV3/NXT Визуальное программирование

⚠️ Внимание при проверке:

Если ученик ответил только «Python» — принять ответ как частичный (1 балл из 2), так как для «Геоскан Пионер» используется Lua. Полный ответ (2 балла) должен включать упоминание нескольких языков в зависимости от платформы.

📋 Задание 5: Симуляция
5 Правильные ответы для заполнения пропусков:

1. Режим имитационного моделирования позволяет...

...тестировать программу без реального робота, запуская виртуального робота на виртуальной трассе.

2. Для запуска программы в режиме симуляции нужно нажать кнопку...

... "Запустить" или "Run" (зеленая кнопка с треугольником ▶) на панели инструментов.

3. В окне симуляции можно увидеть...

...виртуального робота, трассу (поле для движения), датчики робота и процесс выполнения программы в реальном времени.

Примечание: Принимаются ответы, передающие основную суть. Ключевые моменты: тестирование без реального робота, кнопка запуска, виртуальный робот и трасса.
📋 Задание 6: Рефлексия
6 Примерные ответы (принимаются любые осмысленные ответы):

1. Что нового вы узнали о ТРИК Студио?

Пример: Узнал, что это российская программа для программирования роботов, которая поддерживает и визуальное, и текстовое программирование. Можно тестировать программы на виртуальном роботе. Для разных платформ используются разные языки: Python для ТРИК, Lua для Геоскан Пионер.

2. Что показалось самым интересным?

Пример: Возможность создавать программы из блоков-картинок. Интересно, что можно сразу увидеть результат в симуляции. Можно программировать не только роботов, но и квадрокоптеры.

3. Какие вопросы у вас остались?

Пример: Как использовать датчики? Можно ли программировать других роботов? Как создавать сложные программы с условиями? Чем отличается Lua от Python?

Примечание: Это рефлексивное задание. Оценивается осмысленность и полнота ответов, а не их точное совпадение с ключами.
